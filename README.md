# Roast Your Fridge — One Line, One Laugh

Entry for the make.fun bounty
[One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521).

`main.ts` is a small deterministic program (no randomness, no clock, no
network, no input). It writes a single roast line — at most 200 characters —
to `/output/entry.txt`.

The line roasts my fridge on a very specific, recognisable detail: it hums
like it pays rent, hoards leftovers like trophies, and still cannot find the
butter that has been right in front of it since Tuesday.

## Run

```sh
node main.ts
```
